# 贪吃蛇 · Web 端设计文档

- 日期：2026-10-15
- 主题：贪吃蛇小游戏（Web 端）

## 1. 背景与目标

实现一个可在浏览器中直接运行的经典贪吃蛇小游戏。要求轻量、零依赖、零构建，开箱即用。

**成功标准**：双击/打开 `index.html` 即玩；方向键控制蛇移动；吃到食物变长并加分；撞墙或撞自身则游戏结束；可暂停/继续。

## 2. 非目标（YAGNI 排除项）

以下功能本期不实现，后续可按模块化结构追加：

- 难度递增（随分数加速）
- 音效
- 排行榜
- 最高分本地存储
- 移动端触屏/滑动操作
- 障碍物/围墙（标准网格边界即为墙）

## 3. 技术方案

- 单文件 `index.html`，内联 CSS 与 JavaScript。
- 渲染采用 HTML5 `<canvas>` 2D，网格化绘制。
- 游戏循环使用 `requestAnimationFrame` + 时间累积，固定移动节奏（每格约 150ms），保证不同刷新率下节奏一致。
- 无任何第三方库、无构建步骤、无网络依赖。

## 4. 架构与模块划分（单文件内逻辑分区）

| 分区 | 职责 | 关键接口/变量 |
| --- | --- | --- |
| 配置常量 | 网格尺寸、画布大小、配色、移动间隔 | `GRID_SIZE`, `CELL_SIZE`, `MOVE_INTERVAL_MS`, `COLORS` |
| 状态管理 | 蛇身坐标、方向、食物、分数、游戏状态 | `snake`, `direction`, `food`, `score`, `state` |
| 输入处理 | 键盘方向键、Space 暂停、重启键 | `keydown` 监听、方向队列 |
| 游戏逻辑 | 移动、进食、碰撞检测、食物生成 | `step()`, `spawnFood()`, `collides()` |
| 渲染 | 清屏、绘制蛇、绘制食物、状态文案 | `render()` |
| 主循环 | RAF 时间累积、调用 step 与 render | `loop(timestamp)` |

## 5. 数据流

1. 键盘事件更新 `direction`（含反向保护）与 `state`（暂停/重启）。
2. 主循环累积时间，达到 `MOVE_INTERVAL_MS` 时调用 `step()`。
3. `step()`：计算新蛇头 → 碰撞检测 → 吃食物判定（增分、生成新食物）或无食物则移除尾节 → 更新蛇身。
4. `render()`：按最新状态绘制画布与分数/状态文案。

## 6. 游戏规则细节

- 网格：20×20，单元格 24px，画布 480×480。
- 移动方向：上/下/左/右，仅键盘方向键（↑↓←→）。
- **反向保护**：禁止 180° 直接反向，防止瞬间撞到自身；使用方向队列缓冲，避免单帧内两次转向导致误判反向。
- 食物：随机生成于空白格，不与蛇身重叠；若棋盘已满则判胜利。
- 初始蛇长 3，位于棋盘中央，初始向右移动。
- 每次吃食物，分数 +1，蛇身 +1。

## 7. 状态机

```
待开始 -> 运行中 <-> 已暂停
            |
            v
        已结束 -> (按方向键/Enter) 重新开始
```

- 待开始：首次加载，画面提示「按方向键开始」。
- 暂停/继续：`Space` 在「运行中」「已暂停」间切换。
- 已结束：显示最终分数，按任意方向键或 `Enter` 复位重开。

## 8. 错误处理

- 画布获取失败（`getContext` 为 null）：页面输出提示，不静默崩溃。
- 食物生成的空位查找加入安全上限，避免极端情况下死循环。
- 无外部依赖，无网络/资源加载错误面。

## 9. 测试与验收

本项目为无测试框架的单文件前端，验收采用手动冒烟测试：

- [ ] 打开 `index.html` 正常显示棋盘与蛇。
- [ ] 方向键可控制蛇移动，且无法 180° 反向。
- [ ] 吃到食物后蛇变长、分数 +1，食物重新随机生成。
- [ ] 撞墙、撞自身后游戏结束并显示分数。
- [ ] `Space` 可暂停，再次按恢复。
- [ ] 结束后按方向键/Enter 可重新开始。
- [ ] 页面无控制台报错，长时间运行无卡顿。
